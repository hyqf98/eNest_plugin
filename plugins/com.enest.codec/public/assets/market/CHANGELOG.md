# 编解码 Changelog

> 功能参考 [ZTools-plugins/base64](https://github.com/ZToolsCenter/ZTools-plugins)（MIT, ZToolsCenter）

## 1.2.0

- **文件转 Data URL（新增）**：Data URL 模式下选择本地文件（≤8 MB，走宿主文件选择器），生成 base64 Data URL，可一键复制或另存；文件名以胶囊形式挂在输入栏。
- **最近转换记录（新增）**：复制 / 导出 / 回填结果后自动记下最近 24 条（内容截断 4000 字符，持久化到插件存储）；「最近」面板点击即恢复模式、方向与内容。
- **错误定位（新增）**：Base64 / Hex 解码失败时给出中文报错并附「定位第 N 个字符」按钮，点击自动选中首个非法字符。
- **逐行批量可视化**：逐行处理结果以行号列表呈现，失败行整行高亮，不再混排在纯文本里。
- **即时转换提速**：防抖 220ms → 150ms；新增 ⌘/Ctrl + Enter 执行并复制、⌘/Ctrl + U 打开最近记录。
- **界面重构**：模式切换改为分段控件、顶栏半透明材质（`prefers-reduced-transparency` 降级实色）、方向控件固定双段、排印（负字距标题、tabular-nums 数字）、`:active` 按压反馈。

## 1.0.0

- 初始版本
- 四种模式：Base64 / URL / Hex / Unicode 编码与解码，全部中文安全（UTF-8 分块处理）
- 双栏布局，方向一键切换「编码 ⇄ 解码」，支持 Ctrl+Enter 执行
- 输出区一键复制、输入区一键清空 / 粘贴；结果可一键挪回输入并自动翻转方向（互换二次转换）
- 非法输入红条报错（中文提示），不清空已有输出
