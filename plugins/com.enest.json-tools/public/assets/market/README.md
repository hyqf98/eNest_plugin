# JSON 工具

无损数字 JSON 格式化、路径查询、TypeScript 类型生成、统计、树浏览与差异比较。

## 功能

- 格式化 / 压缩 / 键排序 / 校验（错误行列定位）/ 转义与反转义
- 路径查询（`.a.b`、`[*]`、`[0]`、`..name`）与结果提取
- TypeScript interface 生成（结构去重、数组联合类型）
- 统计面板（节点 / 深度 / 体积 / 键 Top 8 / 类型分布）
- 树浏览与搜索、双份 JSON 差异比较

## 使用方式

在 eNest 中打开插件，或使用快捷启动搜索功能名称。主窗口适合连续操作，Quick 适合完成一次任务；可在两种模式之间切换。

## 数据与权限

本插件申请的敏感权限：`clipboard.read`、`clipboard.write`。使用相应系统能力时，eNest 检查清单并请求用户授权；你可以在插件设置中改为允许、询问或拒绝。

插件自身的数据与密钥存储、壳内界面、插件设置、主题和声明式功能入口属于 eNest 的基础能力，直接可用，无需在清单中声明或单独授权。插件仍在隔离环境运行，不能直接访问 Node 或操作系统；读取、写入用户文件须经过宿主的文件选择与句柄 API。
