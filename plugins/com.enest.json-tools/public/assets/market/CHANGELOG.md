# JSON 工具 Changelog

> 功能参考 [ZTools-plugins/json-tools](https://github.com/ZToolsCenter/ZTools-plugins)（MIT, ZToolsCenter）

## 1.3.0

- 文本视图语法高亮：键 / 字符串 / 数字 / 布尔与 null / 标点五类着色（主题 token 派生，深浅主题适配）；带行号列，Quick 模式自动隐藏行号
- 文本视图结构折叠：行号旁箭头按 `{}` / `[]` 块折叠成内联省略（含子项行数）；支持「全部展开 / 1 / 2 / 3 层」快捷收拢；超过 120 行的大结果默认收拢到第 2 层
- 树视图新增「全部展开 / 全部收起」（超 20000 节点自动拦截防卡顿）
- 大文档降级：超过 3000 行或 400 KB 自动回退纯文本，保证性能
## 1.2.0

- 简化路径查询视图：`.a.b` 子键、`[*]` 全部元素、`[0]` / `[-1]` 索引、`..name` 任意层级、`$['键名']` 括号键；结果按 JSON Pointer 展示路径，点击复制值
- TypeScript 类型生成：嵌套对象展开为具名 interface 并按结构去重复用，数组生成元素联合类型（同型压缩为 `T[]`、空数组 `unknown[]`），可自定义根类型名并一键复制
- 统计面板：节点 / 键 / 最大深度 / 体积 / 最长数组 / 去重键数卡片 + 键出现次数 Top 8 + 类型分布
- 格式化缩进新增 Tab 选项（与设置联动）；设置"默认结果视图"扩展 查询 / TS / 统计
- 界面重构：分段控件（格式化 / 压缩 / 键排序 / 校验 / 转义 / 反转义）替代平铺按钮排；结果视图分段切换；工具条与面板半透明材质（`prefers-reduced-transparency` 降级实色）；按钮 `:active` 即时按压反馈；结果区空状态引导
- 权限最小化：移除未使用的 `shell.openExternal`
- 新增纯逻辑自测 `tests/extra.test.mjs`（路径查询 / 统计 / TS 生成，node --test 7 例）

## 1.1.0

- 缩进设置、默认视图设置、自动换行设置（壳子设置页）
- 树视图懒渲染（每次 100 项）、搜索命中列表（前 500 项）
- 差异视图：按路径比较、重复键对象整体比较、复制差异
- Quick 模式原文 / 结果切换；错误定位选中出错字符

## 1.0.0

- 初始版本
- 格式化（2 / 4 空格缩进）与压缩（minify），一键切换
- 校验：JSON 有效时输出节点数 / 最大深度 / 键数统计；失败时按 position 换算行:列，红字定位并选中文本中出错位置
- 转义 / 反转义：字符串与 JSON 字面量互转（塞代码 / 还原）
- 复制结果、清空、粘贴预填；onEnter 文本载荷自动格式化
- 大输入保护：>2MB 提示可能卡顿，>8MB 拒绝处理
