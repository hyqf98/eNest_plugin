# 密码本（password-book）

本地密码本：网站账号密码加密存储，支持分类、搜索、密码强度提示与自动过期提醒，并可通过 MCP 工具让 AI 助手安全读取与写入。

## 安全模型

密码本的核心约束是：**密码明文永不落 `enest.storage`**。

| 环节 | 处理方式 |
| --- | --- |
| 保存 | 前端调用 `enest.vault.set('entry:<id>', password)`，密码进入宿主系统级加密保险库（`vault.write` 权限，首次使用时宿主弹出原生授权）；条目只把返回的不透明 `secretRef` 和元数据（标题、站点、用户名、分类、备注、强度、时间戳）写入插件私有 KV。 |
| 展示 / 复制 | 页面没有明文读取接口。点击「显示 / 复制」时，插件后端（已获 `backend.node` 授权）通过 `secret.resolve` 解密该引用，明文仅在本次调用中定向返回，不写日志、不进存储。复制密码使用 `clipboard.writeText` 并开启 `excludeFromHistory`，不进入剪贴板历史。 |
| 删除 | 删除条目时同步 `enest.vault.remove('entry:<id>')`，元数据与密文一起移除。 |
| 强度 / 生成 | 强度估算（熵 + 常见弱口令 + 重复 / 序列检测）与随机生成（`node:crypto randomInt`，默认排除 `Il1O0` 易混淆字符）都在插件后端完成，不依赖第三方库。 |

`vault.write`、`backend.node`、`clipboard.write` 均在 manifest 中声明，遵循宿主标准授权流程。

## MCP 工具

在宿主设置「开发者 → MCP 服务」启用并复制连接配置后，持有令牌的本机 AI 客户端可以调用本插件的 5 个工具（`pluginId` 为 `com.github.eNest.password-book`）：

| 工具 | 行为 | 说明 |
| --- | --- | --- |
| `list` | 列出条目（标题 / 站点 / 用户名 / 分类 / 强度 / 更新时间） | 只读；结果绝不包含密码或 `secretRef` |
| `get` | 按 `id` 或标题精确匹配返回单条完整信息 | **包含密码明文**（经后端 `secret.resolve` 解密），仅供受信任的 AI 助手在用户明确要求时使用，请勿写入日志 |
| `create` | 新建条目（`title` / `username` / `password` 必填） | 密码写入加密保险库，条目只保留引用与元数据 |
| `update` | 更新条目（`id` 必填，也可用标题精确定位） | 未传字段不动；`password` 可选，传入即替换保险库密文 |
| `delete` | 删除条目（`id` 或标题） | 同步移除保险库密码，不可撤销 |

授权边界：MCP 执行期间沿用插件已获得的敏感权限；若保险库写入等能力尚未授权，宿主返回 `needs-consent`（不会弹出授权框）。请先在插件页面完成一次正常操作完成授权，再让 AI 客户端执行写入。

## 主要功能

- 分类管理：内置「默认 / 网站 / 开发 / 工作」，支持自定义分类（重命名 / 删除，删除时条目归入默认）。
- 搜索：标题 / 站点 / 用户名即时过滤。
- 强度提示：保存与编辑时实时打分（弱 / 中 / 强）并列出改进建议。
- 生成器：长度 8–64，可选大写 / 数字 / 符号 / 易混淆字符，系统级随机源。
- 详情面板：密码默认掩码，显示 / 复制均需显式点击；复制排除剪贴板历史。

数据全部保存在本机（宿主数据根下插件私有存储与加密保险库），不联网、不上传。
