# 漫画屋

聚合漫画阅读插件。导入 JavaScript 格式漫画数据源，即可多源搜索、查看最热排行、浏览详情并沉浸式阅读。

## 功能

- **数据源管理**：官方 / 社区仓库源一键浏览安装；也可粘贴单个 `.js` 源地址或仓库 `index.json` 地址添加；首次打开自动装好精选源
- **搜索**：按源关键词搜索，分页浏览结果
- **排行**：查看数据源提供的最热排行（日榜/周榜/月榜等）
- **阅读**：竖向滚动阅读整章；Ctrl/⌘+滚轮以光标为锚点缩放（0.5×–3×），双击复位
- **浮动侧栏**：阅读时鼠标移近左右屏幕边缘自动展开章节大纲与功能面板，离开自动收起，可固定常驻
- **整部缓存**：详情页一键缓存整部漫画、阅读中可缓存本章，离线可读
- **历史**：自动记录阅读进度，从历史页一键继续阅读

成人向数据源在列表中以「成人」标记警示，由用户自行选择是否安装使用。

数据源脚本由插件后端在隔离的 Node 沙箱中执行，仅按所给地址读取公开页面，不收集任何用户数据。本插件不内置、不提供任何漫画内容；数据源由用户自行导入，请遵守当地法律法规与数据源站点的服务条款。
