# 正则工作台 Changelog

> 功能参考 [ZTools-plugins](https://github.com/ZToolsCenter/ZTools-plugins)（MIT, ZToolsCenter）中的正则测试类插件，结合本壳子 API 自研实现。

## 1.0.0 首版

- 正则输入 + 标志切换（g/i/m/s/u/y），非法正则行内红条提示，不弹窗、不阻塞输入。
- 测试样例多行文本，实时匹配并在样例区以 `--accent-soft` 底色高亮（上限 500 处，防灾难性回溯）。
- 匹配列表：编号 / 全文 / 索引区间，点击列表项滚动定位样例中的对应高亮。
- 捕获分组表：第一个匹配展开 $1..$n 与具名分组 $&lt;name&gt;。
- 替换预览：替换串支持 `$1`、`$<name>`、`$$`、`$&`、`` $` ``、`$'`，结果区逐段 diff（新增绿 / 删除红），一键复制。
- 片段库：内置手机号 / 邮箱 / URL / IPv4 / 身份证 / 日期等 14 条常用正则，点击填充；支持自定义增删，`storage.local` 持久化，可一键恢复默认。
- 速查表抽屉：元字符 / 量词 / 分组引用 / 断言四组速查（桌面形态）。
- 双形态：Quick 紧凑单列（正则 + 样例 + 匹配计数，高亮为唯一视觉重点）；桌面左侧片段库侧栏 + 右侧工作区，≤740px 容器收起侧栏。
- 纯前端实现，权限最小化：`storage.local`（片段库）、`ui.toast`、`ui.resize`。
