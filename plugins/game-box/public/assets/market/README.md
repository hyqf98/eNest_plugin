# 游戏盒子

游戏库与下载器：浏览 PC 游戏、主机游戏与软件，多线程下载后自动解压安装，统一管理启动与卸载。

## 功能

- **游戏库**：PC 游戏、主机游戏、PC 软件，支持分类、排序、搜索与分页；可在两个数据源之间切换（数据源2 的站点目前限制程序访问，可能加载失败）。封面按图片本身的比例显示，不会被裁掉标题与主视觉。
- **详情页**：截图与视频轮播（左右切换、缩略图跳转），站点介绍里的图片与视频原样呈现，流式视频可直接播放。
- **下载**：插件自带的多线程下载器，分片并发、限速、直链过期自动刷新。断点续传精确到每个分片已写入的位置：暂停、断网、关闭插件都不会丢掉已经下载的部分，重新打开后点「继续」从断点接着下。
- **安装**：下载完成后自动解压（支持 zip、7z、rar 与多卷分卷），定位游戏主程序，按设置清理安装包。安装失败与下载失败分开处理，重试安装只重新解压、不重新下载。
- **下载管理**：暂停 / 继续 / 重试 / 删除，全部暂停与全部继续；排队中、解析中、解压中也能暂停，任务和已选目录都会保留。
- **我的游戏**：收藏、已安装与下载中的条目集中管理，启动、关闭、卸载，添加本地已有的游戏。
- **天翼云盘**：在应用内窗口登录天翼云盘（扫码或账号密码，由天翼云盘自己的登录页提供），解析分享链接与提取码，多卷包按组下载。登录会话保存在系统密钥库。
- **修改器 / MOD**：修改器可浏览、排序、搜索与下载，详情页列出功能项与使用指南；MOD 栏目依赖的站点接口目前不稳定，可能暂时无法加载。
- **网盘搜索**：按关键词聚合网盘资源，天翼云盘链接可一键加入下载；也可直接粘贴分享链接下载。

## 说明

- 顶部只有一层导航：发现、我的游戏、下载管理；PC 游戏、主机游戏、软件、修改器、MOD、网盘搜索是「发现」下的栏目。设置与天翼云盘账号在右上角。
- 所有网络请求由插件后端发出并遵循系统代理；页面没有直接联网权限。站点的介绍正文经白名单净化后才显示，图片与视频经插件后端转发。
- 下载目录与安装目录由你在系统对话框中选择，插件只写入你选定的位置。设置里的默认目录只用于预填，每次创建下载任务时需要点「选择」确认一次；关闭「下载后自动安装」时只需选择下载目录。
- 下载任务在插件打开期间进行；关闭插件或退出 eNest 会暂停，重新打开后手动继续。
- 天翼云盘登录需要 eNest 提供应用内登录能力；版本过旧时会提示升级 eNest。登录页由天翼云盘提供并在独立的窗口里打开，账号密码不经过本插件，插件只拿到登录后的会话。
- 天翼云盘的下载接口是社区整理的非官方接口，随时可能失效。
- 本项目为非盈利项目，完全免费开源，禁止任何形式的商用行为。
- 游戏与软件资源的版权归属各来源站点，仅供学习研究。
