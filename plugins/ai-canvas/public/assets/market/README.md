# AI 画布（ai-canvas）

手绘风节点画布 × gpt-image 工作流。

- **自由画布 + 节点编排**：文生图、图生图/编辑、提示词模板、文本输入、本地图片、图片输出六类节点，拖拽连线组成工作流；Excalidraw 式手绘视觉（纸感底、抖动节点框、霞鹜文楷）。
- **Dify 式建图手感**：点击端口旁的 ＋ 弹出节点选择器并自动连线；连线中点插入节点；画布/节点/连线三套右键菜单；拖拽 5px 对齐吸附辅助线；⌘C / ⌘V / ⌘D 复制粘贴、⌘Z 撤销、⌘1 适配、⌘O 自动排版；V/H 双指针模式。
- **标准输出协议**：每个节点的输出按端口固化（文本 / 图片资源引用 / 预留对象），下游经连线自动注入，也可在文本参数里用 `{{#节点.端口#}}` 精确引用任意上游输出。
- **运行与调试**：节点单独运行、只跑下游，或整画布按拓扑序一键跑通；运行中连线流动、节点状态与耗时实时反馈；底部变量检视面板可临时改写某节点输出后再跑下游。
- **OpenAI Images 协议自定义接入**：支持配置多个 endpoint（自定义 baseUrl + API Key + 模型，默认 `gpt-image-1`），密钥走宿主密钥库不落明文。
- **画廊**：全部生成图自动入库，可预览、导出、删除、一键放回画布。
- **持久化**：图片静态资源与画布文档存于 eNest 统一数据根的本插件私有目录；多画布草稿分键存储，切换时记忆各自视口。

## 快速开始

1. 打开插件 → 左下角齿轮（或壳设置 → AI 画布 → 打开设置）→「API 配置」新增一个供应商：填 baseUrl（默认 `https://api.openai.com/v1`）、API Key、模型。
2. 点击端口旁的 ＋（或左轨节点库、右键画布「添加节点」）加入「文生图」节点，写 prompt，点节点右上角 ▶ 运行。
3. 生成结果自动入画廊；「图生图」节点接上游图片继续编辑，「本地图片」节点直接放一张本机图。
