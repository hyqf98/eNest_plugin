# AI 画布（ai-canvas）

手绘风节点画布 × gpt-image 工作流。

- **自由画布 + 节点编排**：文生图、图生图/编辑、提示词模板三类节点，拖拽连线组成工作流；Excalidraw 式手绘视觉（纸感底、抖动节点框、霞鹜文楷）。
- **双模式运行**：节点单独运行，或整画布按拓扑序一键跑通；运行中连线流动、节点状态灯实时反馈。
- **OpenAI Images 协议自定义接入**：支持配置多个 endpoint（自定义 baseUrl + API Key + 模型，默认 `gpt-image-1`），密钥走宿主密钥库不落明文。
- **画廊**：全部生成图自动入库，可预览、导出、删除、一键放回画布。
- **持久化**：图片静态资源与画布文档存于 eNest 统一数据根的本插件私有目录。

## 快速开始

1. 打开插件 → 左下角齿轮（或壳设置 → AI 画布 → 打开设置）→「API 配置」新增一个供应商：填 baseUrl（默认 `https://api.openai.com/v1`）、API Key、模型。
2. 从左侧节点库拖入「文生图」节点，写 prompt，点节点右上角 ▶ 运行。
3. 生成结果自动入画廊；「图生图」节点可接上游图片继续编辑。
