# 批量重命名 Changelog

## 1.1.0

- 新增「插入片段」规则：开头 / 结尾 / 指定字符位（支持负数从尾部计数）
- 新增「删除片段」规则：从开头或结尾第 n 位起删除指定位数（快速去前缀 / 去序号后缀）
- 预览 diff 高亮：新名与旧名的公共前后缀淡化、变化段 accent 着色，一眼看清规则实际改了哪一段
- 冲突分类细化：区分「与现有文件同名」（目标撞批内未改名条目）与「同名目标」（两条改名结果互撞），
  预览头部分别统计冲突 / 非法名数量并禁止执行
- 预览行新增 changed 标记：未变化的行淡化显示「不变」，不再与待改名行混排
- 确认摘要升级：写明队列总数 / 将改名数 / 保持不变数，应用前心中有数
- 工作台布局重构：左（队列 + 规则构建器）右（实时预览）分栏，容器查询 ≤1080px 上下堆叠、≤740px 单列
- 交互反馈补全：ghost / danger 按钮 hover 与 :active 按压位移；拖拽手柄提示；文案断行保护（word-break）

## 1.0.0

- 初始版本
- 文件队列：拖入（localFiles.fromDrop）或选择器添加，按名称 + 大小去重，单文件移除 / 清空
- 规则链：查找替换（可正则 / 大小写）、序号（start / step / width / 前后缀 / 分隔符 / 纯序号）、
  日期（mtime 或当前时间，YYYY MM DD HH mm ss 模板）、大小写（上 / 下 / 首字母）、扩展名替换；
  拖拽排序、坏正则即时报错
- 实时预览：原名 → 新名 + 冲突（同目录同名）/ 非法名标注，被阻止时禁止执行
- 执行：确认对话框 → fs.renameBatch(confirmed)；结果报告 toast + 失败明细
- 撤销：成功映射（to → from）持久化到 storage，跨会话可撤销上次改名
