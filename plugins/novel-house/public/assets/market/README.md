# 小说屋

聚合小说阅读插件。导入 Legado（阅读3.0）格式书源 JSON，即可多源搜书、分类浏览、查看详情并舒适排版阅读。

## 功能

- **书源管理**：兼容 Legado（阅读3.0）书源格式——对象或数组 JSON 均可，支持在线仓库整仓导入、粘贴批量导入；首启自动装好精选源
- **搜索**：按书名/作者搜索，搜索框带历史记录与在线联想（输入法组合态防抖）；分页浏览结果
- **分类**：浏览书源提供的分类书单（玄幻/都市/科幻等）
- **阅读器**：舒适文字排版——字号/行距/段距/版心宽度实时调整，纸张/纯白/护眼/夜间四底色；⌘/Ctrl+滚轮调字号；Esc 退出、←/→ 切章
- **浮动侧栏**：阅读时鼠标移近左右屏幕边缘自动展开目录与功能面板，离开自动收起，可固定常驻
- **整本缓存**：详情页一键缓存整本、阅读中可缓存本章，离线可读
- **书架与历史**：收藏进书架；自动记录阅读进度（章节+滚动位置），从历史页一键继续

书源规则由插件后端在隔离沙箱中解析执行；出网请求由后端统一代理转发，不收集任何用户数据。本插件不内置、不提供任何小说内容；书源由用户自行导入，请遵守当地法律法规与书源站点的服务条款。
