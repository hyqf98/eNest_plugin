# 环境变量管理

跨平台环境变量管理：macOS 与 Windows 用户 / 系统变量分区查看、编辑、写入与删除，PATH 专用编辑器，写入前自动备份。

## 平台支持

| 平台 | 数据来源 | 写入方式 |
|------|----------|----------|
| macOS | `~/.zshenv` / `~/.zprofile` / `~/.zshrc` / `~/.zlogin` 解析 + 当前进程 | eNest 受管块（可配置目标文件），可选同步 `launchctl` |
| Windows | 用户 / 系统注册表环境变量 + 当前进程 | `[Environment]::SetEnvironmentVariable`，系统变量自动请求提权（UAC） |

## 功能

- **分区查看**：范围列表按用户 / 系统（或持久化 / 进程）分区统计，同名变量多处定义全部展示并标注冲突
- **搜索**：顶栏按名称 / 值即时过滤
- **编辑与新增**：等宽编辑器修改变量值；macOS 写入前提示目标文件
- **删除**：只动 eNest 受管块内的定义，不删用户手写行（macOS）；危险操作二次确认
- **PATH 专用编辑器**：每行一条，上移 / 下移 / 删除 / 新增，按顺序拼回；macOS 附 `/etc/paths` 与 `/etc/paths.d/*` 来源视图
- **自动备份**：macOS 每次写入前备份目标文件（保留最近 5 份），可随时恢复；恢复前同样先备份当前版
- **来源可溯**：每条变量标注来源文件与行号、注册表来源、是否在 eNest 受管块、是否含 `$(...)` / `${...}` 动态引用

## 安全设计

- 变量名严格白名单校验，PowerShell 拼装统一单引号转义，杜绝注入
- 文件操作仅限 `~` 下固定四个 zsh 配置文件及其备份 / 临时文件，拒绝路径穿越
- 所有命令经 `execFile` 执行，永不经过 shell；输出截断到 1 MiB

## 已知边界

- macOS 持久化写入只影响新开的 shell 会话；GUI 应用立即生效需开启 launchctl 同步（重启后失效）
- Windows 系统变量写入依赖 UAC 提权确认，取消即放弃本次写入
- shell 配置中 `$'...'`、续行等复杂语句仅展示不解析
