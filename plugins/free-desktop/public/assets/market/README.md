# 自由桌面

打开插件先进入普通工作区。拖动画面空白处，选择创建收纳区、文件夹、时钟或便签。可拖动卡片标题或右下角调整位置、大小。布局保存在插件私有存储，与自由画布无关。

首次可以在工具栏选择「原桌面文件区」，在系统选择器里批准桌面目录，也可以跳过。收纳区只保存引用，移除引用或区域不会删除文件；文件夹区显示已授权目录的直接子项。在工作区明确选「移入文件」并确认时才会移动一个同卷普通文件，遇到同名不会覆盖，不递归搬移目录。文件权限、壁纸和启动项在 eNest 的插件工作区配置；原生桌面上的「打开工作区」可切回既有实例，不替你确认授权。

整个桌面只有一条程序栏，默认在主屏底部，可指定显示器和四边位置。拔掉指定显示器时临时回到主屏，重连后回到原位。按住程序图标拖动排序，右键可移除。点击搜索打开 eNest Quick；桌面插件不获得全盘文件检索结果。后台唤起 Quick、固定程序或工作区需要本次会话的「启动栏」授权，拒绝不影响文件和布局。

「接管系统桌面」需要信任本插件的本机后端（`backend.node`，完整本机信任）。仅启动包内对应平台的 helper，不下载安装额外软件，不修改系统壁纸、不终止 Finder 或 Explorer、不替换登录外壳。托管层在普通应用下方；可以从桌面工具或插件工作区退出。进程退出、插件关闭或卸载都会释放原生窗口，保留原来的系统桌面。

未包含对应架构的 helper、窗口管理器不提供合适层级或 WebView 不可用时，插件保留普通窗口工作区并说明原因。Wayland 需要合成器提供 layer-shell 的按需键盘交互；没有就不接管。桌面接管不在重启后静默开启。
