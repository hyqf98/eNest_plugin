# 自由画布

在管理器中选择显示器，点击「在屏幕上框选」并拖出一块区域。这个临时选区只读取鼠标位置，不截屏、不录屏。你也可以直接创建普通窗口，不使用置顶权限。

- 在画布空白处拖动，决定新组件的位置和大小；松开后选择计算器、番茄钟、便签、进程概览、时钟或待办。组件标题可拖动，右下角可拉伸。
- 点击画布标题栏的移动控件并拖动可移动整个画布；右下角可改变画布窗口大小。在管理器里可选择置顶模式，然后打开画布。
- 便签和待办保存于本插件，不读取同名业务插件。番茄钟保存到期时间，关闭窗口不会重置倒计时。进程概览只在用户点击「采样」时请求 `sys.inspect`；展示的是进程 CPU 与 RSS 合计，不是整机内存占比。
- 「关闭」只关闭窗口；「移除」才删除该画布。重新启动后由你决定打开哪一块，不自动占用桌面。
- 在宿主导出旧面板布局后，使用「导入旧布局」选择 JSON 文件。只导入可识别的几何信息，不修改原文件，不加载第三方组件。
