# 影视仓

导入 TVBox / 影视仓格式影视配置源，桌面端聚合观影。

## 功能

- **配置源管理**：URL / 粘贴 JSON 导入，多仓（urls）多线路一键切换，内置开箱即用的采集站配置。
- **站点浏览**：分类 tab + 类型/地区/年份/排序筛选，海报墙无限加载；站点可启停。
- **聚合搜索**：多站点并行搜索，结果按站点动态聚合；支持快速搜站点范围。
- **多线路播放**：详情多线路（flag）选集，hls.js 页内播放，倍速/选集抽屉/线路切换，播放进度记忆续播。
- **JS Spider 源**：type 3 纯 JS 爬虫源（drpy2 运行时）沙箱执行；.jar / .py 源不支持。
- **直播源**：lives txt（#genre# 分组）/ m3u 解析，频道分组、多线路切换、频道收藏。
- **收藏与历史**：跨站收藏、观看历史与续播进度。

## 说明

- 所有网络请求经插件后端代理（走系统代理），页面无直接网络权限。
- 视频经本机回环代理转发（处理防盗链 Referer/UA 与 CORS），不落盘。
- 仅供学习研究，内容版权归属各源站点。
