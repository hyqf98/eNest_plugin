# AI 生图（image-gen）

对话式 AI 生图工具：一句提示词出图，多渠道接入，图生图以图续作。

- **对话式生成**：会话流里发提示词即生成；用户消息可复制、重新编辑回填；AI 消息展示图片网格、模型/尺寸/耗时与用量，支持重新生成、以此图继续、全部下载。
- **三类协议**：渠道按 OpenAI Images（/images/generations + /images/edits）、Chat Completions 多模态、Responses（image_generation 工具）三种协议接入，兼容官方与 one-api / new-api 等中转站；模型列表可从接口拉取，按图片模型启发式过滤。
- **图生图**：⌘V 粘贴、📎 选图或整窗拖入最多 4 张附件；「以此图继续」把任意结果图转为下一轮编辑输入。
- **生成参数**：尺寸（自动/1:1/3:2/2:3）、数量 1-4、质量档位；提示词模板（⭐ 菜单一键追加）。
- **预览库**：全部生成记录按时间倒序分组，方格缩略墙懒加载；筛选渠道/模型，多选批量下载或删除。
- **保存位置**：默认插件资产库，可选自定义目录同步写盘（目录失效自动落回资产库并提示）。
- **安全**：密钥仅存宿主密钥库（vault secretRef），请求经宿主受控网络层；图片预览一律经资源库转 blob URL。

## 快速开始

1. 打开插件 → 左下角齿轮 →「渠道」新增：填名称、接口地址（自动补协议头与 /v1）、API Key、模型（可拉取列表），保存自动测试连通。
2. 在输入框描述画面，Enter 发送；尺寸与数量在输入框上方参数条调整。
3. 结果图 hover 可继续编辑、下载、删除，点击进大图预览（滚轮缩放、方向键翻图）。

## 说明

- Chat / Responses 协议下「尺寸」会翻译成提示词后缀（如「，画面比例 3:2 横构图」），原始参数记录在消息 meta。
- 会话与生成记录存插件私有存储；图片存 eNest 数据根下本插件私有资产库。
