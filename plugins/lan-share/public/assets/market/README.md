# 局域网传件

同一 Wi-Fi 下把文件发给手机：取件码 + 二维码即扫即下，限时自动关闭，下载实时日志。

## 功能

- 局域网传文件

## 使用方式

在 eNest 中打开插件，或使用快捷启动搜索功能名称。主窗口适合连续操作，Quick 适合完成一次任务；可在两种模式之间切换。

0.0.1 起需要 eNest 0.2.2 及以上版本，并单独授权 `backend.node` 本机后端能力；旧版局域网分享授权不会自动授予此能力。HTTP 分享服务、取件码、Range 下载与到期策略均由本插件实现，壳只管理本机后端生命周期和用户选择的文件句柄。

选择文件或确认拖入后，点击「开始分享」才会监听局域网。关闭插件、手动停止或到期会停止服务并中止仍在传输的连接。单文件最多 4 GiB，采用有界流式读取，不将整个文件加载到内存。HTTP 传输不加密，取件链接包含访问凭据，请勿将端口暴露到公网。
