# Cron 工具 Changelog

> 功能参考 [ZTools-plugins](https://github.com/ZToolsCenter/ZTools-plugins)（MIT, ZToolsCenter）中的 Cron 类插件，结合本壳子 API 自研实现。

## 1.1.0

- 未来执行预览次数可调：5 / 10 / 20 次分段切换（默认 10 次，选择持久化）
- 执行列表双时间显示：绝对时间（本地/UTC 主列 + 对照列）与相对时间（"xx 分钟 / 天 / 年"）并列，30 秒自动刷新
- 中文人性化描述增强：工作日 `1-5` 压缩为「周一至周五」、`0,6` → 「周末」；时段词（凌晨 / 早上 / 上午 / 中午 / 下午 / 晚上）；日与周同时受限明确读作「或」
- 表达式错误精确定位：报出第几个域、哪个域、什么问题（"第 2 个域「时」：超出范围：61"）
- 显式拒绝 Quartz 专有语法：`L` / `W` / `#` / `?` 给出中文提示，避免静默误解析
- nextFire 计算重写：月/日跳跃扫描替代逐分钟遍历，正确命中闰年 2 月 29 日、月末 31→1、跨年边界；扫描上限 4 年提升至 50 年（10 次闰年扫描实测 ~12ms）
- 5/6 域切换改分段控件；预设库扩充至 16 条（新增 每天早9点 / 每 10 分钟 / 每周五晚 6 点 / 每半年）
- 界面重构：顶栏半透明材质（`prefers-reduced-transparency` 降级实色）、执行表 sticky 表头 + 数字 tabular-nums、按钮 `:active` 按压反馈
- 纯逻辑自测扩充至 10 例（含闰年 / 月末 / 跨年 / L W 拒绝 / 域定位边界）

## 1.0.0 首版

- 五域可视化构建器（分 / 时 / 日 / 月 / 周）：每域快捷片断（`*/n`、区间、列表、指定值）点选生成，手动输入框兜底，双向同步顶部表达式。
- 秒级 Quartz 风格开关：切换为 6 域（秒 分 时 日 月 周），构建器与解析同步适配。
- 表达式 → 自然语言：中文描述（"每 5 分钟"、"每周一 08:30"、"每月 1,15 日" 等）。
- 下次执行预览：未来 5 次执行时间（默认本地时区，列 UTC 对照，可切换主列时区），30 秒自动刷新，附倒计时。
- 预设库：内置每天凌晨 3 点 / 工作日 9 点 / 每小时 / 每月 1 号等 12 条，点击载入；可保存当前为自定义预设（`storage.local` 持久）、可删除、可一键恢复内置。
- crontab 行粘贴解析：支持 `@daily` / `@hourly` / `@monthly` / `@weekly` / `@yearly` 等宏与注释行，逐行报错（行内状态 + toast）；导出复制为 crontab 条目（含中文注释）。
- 非法表达式行内红条提示，不弹窗不阻塞。
- 双形态：Quick 单输入即解析 + 下次 3 次预览（隐藏构建器与 crontab 面板，UTC 对照列折叠）；桌面全量构建器 + 预设侧栏。
- 纯前端实现，权限最小化：`storage.local`（自定义预设）、`ui.toast`、`ui.resize`。
- 核心纯逻辑（域解析 / 下次执行扫描 / 中文描述 / crontab 宏 / 格式化回写）在 `tests/core.test.mjs` 覆盖自测。
