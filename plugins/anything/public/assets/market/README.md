# Anything 文件搜索

全盘文件即时搜索，向 Everything / Spotlight 借力：输入即出结果，命中高亮、排序分页，回车打开、定位目录、移入废纸篓，常用文本与图片直接预览。

## 引擎

| 平台 | 引擎 | 说明 |
|------|------|------|
| macOS | Spotlight（mdfind） | 系统索引，开箱即用，毫秒级 |
| Windows | Everything（HTTP 服务） | 需自行安装 Everything 并在 选项 → HTTP 服务器 中开启，再到本插件偏好设置填端口（可选用户名:密码） |
| Linux | 暂不支持 | 后续版本提供 |

## 搜索语法

- 多个关键词：同时命中文件名即匹配，顺序不限（`报告 pdf`）
- `"精确短语"`：引号内内容按连续短语匹配
- `-排除词`：剔除命中的结果（`logo -png`）
- `*` 通配符（`*.sketch`）

## 快捷入口

- Quick 搜索条输入触发词：`anything`、`文件搜索`、`本地搜索`、`find`
- 选中任意文本叠加「文件搜索」指令，直接以该文本为关键词进入搜索
- 插件运行期间，Quick 主搜索直接推送前 8 条文件结果，回车即打开

## 操作

- `↵` 打开（Quick 中打开后自动收起）/ `⌘↵` 所在目录定位
- 单击选中预览（文本按编码探测展示，图片内嵌渲染）
- 复制路径、移入系统废纸篓（可恢复）

## 已知边界

- macOS 依赖 Spotlight 索引：系统隐私设置中排除的目录不会被搜索到，可用「范围」限定到指定目录补足
- 预览面向文本与图片；PDF、压缩包等交给系统应用打开
