# 媒体浏览

关联多个文件夹，在一个窗口里浏览、整理其中的图片与视频。

## 能做什么

- **关联多个文件夹**：通过系统目录选择器添加，随时取消关联。每次打开需要重新授权（出于安全，授权不会跨会话保留），上次关联过的目录会列出来方便重新选择。
- **各种图片格式**：JPG、PNG、GIF、WebP、BMP、TIFF、SVG、HEIC、AVIF，以及相机 RAW——尼康 NEF / NRW、佳能 CR2 / CR3 / CRW、索尼 ARW、富士 RAF、奥林巴斯 ORF、松下 RW2、宾得 PEF、DNG 等。RAW 直接取相机内嵌的预览 JPEG，不重新解码原始数据。
- **视频**：MP4、MOV、WebM、MKV、AVI 等，卡片缩略图取视频首帧（需要本机装有 ffmpeg），点击播放。
- **左侧树**：关联目录 → 子文件夹 → 文件，层级可折叠。
- **右侧卡片网格**：图片与视频样式一致，视频只多一个播放按钮；滚动到才加载缩略图。
- **整理**：把文件或文件夹拖到左侧任意文件夹即完成真实移动；按住 Shift 范围选择、Ctrl / Cmd 追加选择，左右两个面板都支持。
- **删除**：按 Delete 直接删除当前文件；批量与整个文件夹的删除会先弹出系统确认。

## 注意

- **删除是永久删除，不进回收站。** 批量删除与删除文件夹前会经系统确认框二次确认，单文件按 Delete 不提示。
- 移动与删除都直接作用于磁盘上的真实文件。
- 视频缩略图依赖本机 `ffmpeg`；没有安装时视频卡片显示格式占位，仍可正常播放。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `←` / `→` | 预览时切换上一个 / 下一个（视频播放时归播放器） |
| `Delete` | 删除当前预览的文件 |
| `Esc` | 关闭预览 |
