# 更新记录

## 1.2.0

- **配色全面重做**：去掉发闷的灰绿桌面，改为四套 mesh 渐变桌面（多层 `radial-gradient` 光斑 + `linear-gradient` 底色 + SVG 颗粒）。默认「暖沙日光」：近白到浅暖灰的桌面上落着暖橙与淡金两团光，纸提到纯白，与桌面拉开对比。另外三套：晨雾中性 / 陶土纸感 / 冷雾青灰。
- 色板来自 Tailwind 真实色阶（stone / orange / amber / sky / teal），墨色改 stone-800，马克笔 orange-700。
- **四套桌面预设可在设置里切换**，深色模式各有对应版本。
- **设置页对齐壳的设置页**：顶部横向 tab + 单列卡片 + 左标签右控件的字段行，右列宽度与壳同为 `--settings-control-width: 280px`，分段控件沿用壳的胶囊造型，开关/滑块/颜色圆点与壳一致。不再使用左侧书签栏 + 纸板的自造布局，也不引入纸品手绘层 —— 它是可信设置界面的一部分。
- **设置精简**：从 5 组 36 项合并到 4 组 17 项（外观 / 版面 / 手写 / 细节）。去掉重复的 13 项色卡，只保留纸张、墨色、马克笔、盖章绿/红 5 个真正会调的颜色；内容宽度、通知圆角/强调/描边/密度等并入其它组或跟随预设派生。
- **修复卡片被裁切**：`grid-auto-rows` 从固定 `92px` 改为 `minmax(92px, auto)`，卡片不再 `overflow: hidden` 裁内容。之前「已安装 / 详情 / 打开」在纸片底边被切掉。
- **修复设置页握手超时**：`ready()` 从"取完快照之后"提到"拿到桥立刻调用"，订阅与首帧都加 try/catch 兜底。之前任何一步异常都会拖死 8 秒握手，表现为顶部出现「主题设置暂不可用」。
- 宿主侧：失败提示从顶部整条横幅改为右下角浮动小卡片，不再在页首压出一条横条。

## 1.1.1

- **修复目录空洞**：首页不再用固定节奏表。各组张数不是 6 的倍数时（设计组 1 张、媒体组 2 张）固定跨度必然留空 —— 实测空洞率 11.7%，设计组高达 50.5%。改为按真实张数现算的**带式铺砖**：带横跨满宽、带内列宽之和等于列数、带间首尾相接，于是任意张数 × 任意列数（1..40 张 × 1..6 列已全部验证）都严格铺满。
- 有效列数由 JS 按视口与宿主设置算一次写进 `--sk-columns`，网格列数与每张卡的行列跨度**同源**，窗口缩放时重算重排。
- **修复高纸片内部空白**：截图改放在 `.sk-card-clip` 里绝对定位 `object-fit: cover`，不再让 `<img>` 的固有比例参与 flex 计算（曾把纸片从 320px 撑到 616px）；胶带、图钉、折角改为绝对定位，不再各占 19/21px 挤压剪贴画。
- 内容密度按"能放下多少"分级：3 行以上的 `wide`/`tall` 贴截图并吃满剩余高度，2 行的 `stamp` 只放标签与批注（贴图会把页脚顶出去），`stub` 只留标题与主操作。
- **详情双栏严格等高**：外框 `max-height: min(64vh, 720px)`、子面板 `min-height: 0`，截图区与说明各自在超限后内部滚动；窄视口改单列、不做双滚动条。
- **新增常驻自动动效**（不需悬停）：纸片浮动、精选呼吸、剪贴画呼吸、胶带起伏、分类墨条呼吸、涂鸦摆动，全部按 `--sk-i` 相位错开；线条沸腾在高档作用于全部纸片。
- 修复入场动画与常驻动画互相覆盖：入场只碰 `opacity/scale/rotate`、常驻只碰 `translate`；`animationend` 收窄到 `target === node && !pseudoElement` 并加 1200ms 兜底，避免纸片永远卡在入场态。
- 低动效档下全部自动动效停止（含 `::before` / `::after` 伪元素动画）。

## 1.1.0

- **全量重做视觉系统**：从"圆角卡片 + 六色彩条"改为纸品系统 —— 索引卡 / 方格纸 / 牛皮纸 / 相纸 / 便签五种纸各有纸色、纹理与分级投影；纸是直角物件，圆角只用于控件。
- **首页改为不规则拼贴**：六张纸一组（1×4 / 1×2 / 2×3 / 2×4），面积正好铺满 4 列 × 7 行，经穷举验证无空洞；余数由 `dense` 回填。每张纸用真实截图、手绘速写页、标签与铅笔批注填满，不再留空白纸边。
- **新增手绘动效**：线条沸腾（三个不同种子的位移滤镜按 3 帧轮换）、纸片掀起（悬停时纸角翻起）、胶带压实。
- **新增自绘设置页**（`settingsPage`）：左侧书签条 + 右侧方格活页纸，颜色字段切成色卡网格，选项渲染成纸样卡；只使用宿主发布的字段句柄，原生安全入口保留。
- 设置参数重排为五组共 36 个字段（纸与墨 / 纸面与桌面 / 手写与字号 / 纸面陈列 / 纸边与通知），新增桌面铺色、漂移速度、纸纹颗粒与列数。
- 深浅两套配色重做：浅色为灰绿桌 + 暖白纸（`#a8c0b4` / `#f9f6ef`），深色为暖墨木桌（`#1a2224` / `#2b3234`）；墨色改为暖白，投影更实。
- 精选推荐改为主推剪报 + 两枚索引卡，三张等高；主推标题独占一行、剪贴画通栏。
- 共享纸面层下沉到 `lib/`（`paper.css` / `paper-ui.css`），样式台、Quick 与首页复用同一套控件。
- 修复：`plugin.json` 的 JSON 导入不再声明 `with { type: 'json' }`（Vite dev 返回 `text/javascript`，严格 JSON 模块校验会拒绝整条 import）。

## 1.0.3

- 修复切换素描本主题时首页握手超时并回退默认主题：只声明宿主支持的目录与详情路由。
- “已安装”改为插件自己的目录筛选；从详情关闭、后退或宿主导航回目录时保留筛选，不再发送旧的已安装路由。
