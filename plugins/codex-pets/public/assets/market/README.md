# Codex 宠物市场

浏览 [codex-pets.net](https://codex-pets.net) 社区宠物画廊，并把心仪的桌面宠物一键安装到本机 Codex（`~/.codex/pets`）。

## 功能

- **画廊**：搜索、五种排序（最新 / 最多赞 / 最多浏览 / 最多讨论 / 随机）、标签 + 类型 + 格式 + 内容分级筛选、页码分页（每页 30 只，随机模式 3 只）
- **动效复刻**：卡片默认海报静帧，hover 后加载完整 spritesheet 并按宠物 id 确定性选中动画行逐帧播放；光标跟随迷你宠物（移动奔跑、静止待机、久等环顾，随速度倾斜）
- **详情页**：大舞台 + 11 个动画状态（V1 旧版宠物为 9 个）+ V2 宠物的 16 方向视线罗盘 + 包校验信息（格式 / 图集 / 行数 / 体积）+ 更多宠物推荐
- **一键安装**：自动检测本机 Codex（`~/.codex/config.toml`）→ 下载 `.codex-pet.zip` → 本地校验（pet.json 与图集尺寸匹配）→ 经宿主确认写入 `~/.codex/pets/<id>/`，覆盖前自动快照；另提供 CLI / curl 安装命令复制与 zip 导出
- **已安装管理**：扫描 `~/.codex/pets`、与线上版本比对、重装 / 更新 / 删除

## 安装到 Codex 后如何启用

在 Codex 的 **设置 → Pets**（或会话里输入 `/pet`）选择刚安装的宠物。

宠物作品由 codex-pets.net 社区分享，部分角色为社区二创；版权与下架诉求请到[原项目 issue](https://github.com/portons/codex-pet-share) 反馈。
