# Changelog

## 0.3.1（2026-10-23）

- 要求 eNest 0.2.1 或更新版本。将 DSH 内核管理、Profiles、会话读取、下载升级、备份及相关依赖迁入插件自身的 Node 后端；壳不再包含 DSH 专用业务处理器。
- 改用标准 `backend.node` 权限，首次使用需明确授权，旧版 DSH 专用权限不会自动继承。沿用原有数据、内核和备份路径，保留现有管理功能。
- 在壳设置中声明标准 `page` 入口，直接打开插件自绘的管理中心，不把业务表单放回壳子。
- 长任务通过任务事件返回进度和结果，不延长宿主通用 RPC 超时；任务及运行中的子进程持有活动租约，避免切换页面后被空闲休眠中断。
- 关闭时取消启动、下载与重试，等待真实子进程退出；宿主对已登记的进程提供退出确认和超时回收，未确认退出前不启动下一代后端。
- 内嵌 Web 入口在宿主确认后开放，仅允许当前后端拥有的子进程显式端口；下载和重定向逐次采用宿主当前代理配置。

## 0.3.0（2026-10-23）

- 图标换用 DeepSeek 官方鲸鱼剪影（品牌蓝底白鱼）。
- 发行包不再内嵌 DSH 内核（安装包从 ~150MB 降至约 500KB）；首次打开发现无可用内核时弹出安装引导，在线选择已发布版本，下载经 SHA-256 校验、健康检查后自动激活；已有本地或系统内核则不弹。
- 新增独立管理中心和 `dsh管理` / `dsh设置` 启动入口，统一运行、内核版本、Profiles、维护与诊断。
- 支持 Web / SDK 分别启停与失败后重启，首选端口占用自动换口；关闭插件取消启动重试并回收进程。
- 支持宿主持久化 Web / SDK Profile 选择，编辑组合补丁及受限子进程环境变量，默认遮罩密钥。
- 新增一键同步 Profile 环境，保留目标运行组合；覆盖前备份，停止进程后下次启动生效。
- 补齐内核版本切换、捆绑内核回退、SHA-256 边车解析、安装暂存及升级回滚，扩展跨平台内核资产发布。
- 新增自动备份后的配置重置与完整环境重置，默认保留会话，不触碰系统 DSH、已安装内核和备份。
- 修复自定义 Web Profile 启动参数、首次目录缺失、删除前备份参数、未等待退出就恢复数据、管理页状态不刷新等问题。

## 0.1.0（2026-10-13）

- 首版：小窗会话驾驶舱（多会话进度/切换/快速对话）、大桌面 iframe 完全体、独立设置台（Profile 管家/端口策略/版本与升级/备份/诊断）。
- 自包含 dsh 运行时（Electron RunAsNode 引擎）、端口冲突自动换口、插件关闭自动回收进程与端口。
- 宿主侧新增 `dsh.connect / dsh.chat / dsh.admin` 三档权限与 `net.embedLoopback` CSP 门控。
