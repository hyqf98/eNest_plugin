# Changelog

## 未发布（2026-10-22）

- 新增独立管理中心和 `dsh管理` / `dsh设置` 启动入口，统一运行、内核版本、Profiles、维护与诊断。
- 支持 Web / SDK 分别启停与失败后重启，首选端口占用自动换口；关闭插件取消启动重试并回收进程。
- 支持宿主持久化 Web / SDK Profile 选择，编辑组合补丁及受限子进程环境变量，默认遮罩密钥。
- 新增一键同步 Profile 环境，保留目标运行组合；覆盖前备份，停止进程后下次启动生效。
- 补齐内核版本切换、捆绑内核回退、SHA-256 边车解析、安装暂存及升级回滚，扩展跨平台内核资产发布。
- 新增自动备份后的配置重置与完整环境重置，默认保留会话，不触碰系统 DSH、已安装内核和备份。
- 修复自定义 Web Profile 启动参数、首次目录缺失、删除前备份参数、未等待退出就恢复数据、管理页状态不刷新等问题。

## 0.1.0（2026-10-13）

- 首版：小窗会话驾驶舱（多会话进度/切换/快速对话）、大桌面 iframe 完全体、独立设置台（Profile 管家/端口策略/版本与升级/备份/诊断）。
- 自包含 dsh 运行时（Electron RunAsNode 引擎）、端口冲突自动换口、插件关闭自动回收进程与端口。
- 宿主侧新增 `dsh.connect / dsh.chat / dsh.admin` 三档权限与 `net.embedLoopback` CSP 门控。
