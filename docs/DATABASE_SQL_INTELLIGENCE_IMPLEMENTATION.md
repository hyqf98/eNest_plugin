# 数据库 SQL 智能提示实现

状态：首版及配置、冷启动联想与取消链路补强已实施。日期：2026-10-14。目标插件：`plugins/database`。

交互按用户最新决定统一为光标下方候选列表。原先字段展开与整条查询生成的预览确认弹框已取消；类型、备注、函数签名和 SQL 简略内容在候选行内显示，不打开独立的补全详情浮面板。

实现基于原有 Monaco、轻量编辑器与 `db.ui`，没有新增宿主接口、权限、驱动或第三方解析依赖。原先插件侧的平面正则回退、固定前 40 表预热和普通 SQL 的宿主优先请求已移除。普通 SQL 统一由本地引擎处理，其他查询语言继续通过隔离的只读会话调用既有驱动补全。

## 已实现的使用方式

- 在 `SELECT c.na| FROM customers c` 的光标处补全字段，即使尚未打开树中的表。
- 输入 `sel` 即可在冷目录中列出目标表查询；接受候选后只读取所选表的字段。`SELECT cust|`、`sel customers|` 也可懒读字段并生成查询。工具栏“模板”使用同一候选列表，选中后直接替换当前简单输入，不覆盖复杂查询正文。
- 将光标放在 `SELECT *` 或 `c.*` 上，使用工具栏“展开字段”、命令面板或候选菜单，在同一列表选择全部字段或已配置的常用字段组，直接插入结果。`COUNT(*)` 和无法安全推导的投影不展开。
- 同一查询块的别名、CTE、派生表、相关子查询和 UNION 分支分别解析；优先利用完整复合外键生成 JOIN 条件。
- 根据 INSERT / UPDATE 位置提示适用字段；候选行显示字段类型、备注或函数签名；静态枚举可提示字段值。可配置 SELECT 星号、重复别名、未知列和无条件修改提醒。
- 在设置的“SQL 智能提示”中调整自动提示、延迟、最小前缀、Enter / Tab 接受、大小写、自动别名、备注搜索、使用频率和候选上限。
- 字段组支持从当前 SELECT 提取物理字段、从结构选字段、手工录入、拖动和键盘排序，保留完整表作用域。含表达式、星号、CTE／派生输出或多表投影时就地说明原因，不猜测字段。
- 函数、带类型的静态枚举和局部规则均提供可视化编辑；局部规则逐项显示覆盖与继承。模板支持常规 snippet 和 SELECT / INSERT / UPDATE 生成器、固定字段组、别名及建议位置。Monaco 支持编号占位符跳转。
- 高级 JSON 保留排序固定项和表单之外的声明式配置。导入前校验、预览冲突并映射连接；导出不包含连接配置或凭据。无效数值与保存失败保留草稿。
- 设置页实时试验区使用同一个引擎，可以查看建议和页内文本预览，不执行 SQL，也不在编辑器补全流程中增加确认步骤。保存失败保留草稿。

函数当前参数信息也位于同一个候选列表，信息行点击或接受不会把签名写入 SQL。FROM／JOIN 的对象位置只显示适用对象，已知外键相关表优先。提示字号与行高跟随编辑器设置。

普通字段、字段展开、常用字段组和整条查询生成都在光标下方列表直接接受。Tab／Enter 的接受行为跟随设置，Escape 关闭列表；没有额外的补全确认弹框或详情浮面板。接受后是一条撤销操作。文档内容、连接上下文、配置或相关元数据变化后，先前的候选不能写入新目标。

## 代码结构

模块边界和扩展步骤见 `plugins/database/src/js/sql-intelligence/README.md`。

```text
编辑器 / 设置试验区
  → completion.js 适配层
  → runtime 上下文、配置、请求代次
  → Worker：syntax → providers → ranking → EditPlan
  → 光标下方候选列表 → 编辑器校验来源 → 直接应用 → 撤销栈

runtime → metadata 独立只读会话 → 宿主既有 db.schema API
```

增加方言只扩展 `dialects/`；增加候选来源只扩展纯 provider；持久化规则由 `configuration/` 校验，UI 使用 `settings/`。Worker 输入采用类型白名单，连接对象、凭据和宿主句柄不会进入分析线程。Worker 一次运行一个任务，等待队列最多 32 项，同文档／方法／通道的新请求替代旧请求；被替代的运行任务终止 Worker，其他文档的等待请求保留。Monaco 的取消令牌与轻量编辑器的 Escape、编辑、移动和文档切换接入 AbortSignal，不中止共享只读读取或用户执行任务。

候选接受前校验模型版本、目标上下文、配置、连接失效代次及所依赖对象的快照／TTL；不相关表的惰性读取不会让当前候选无效，同名对象新增导致歧义则拒绝旧改写。

对象规则的数据库／Schema／表条件在解析并绑定对象后匹配；显式跨 Schema 或 MySQL 跨库查询不会被编辑器默认库提前过滤。省略 namespace 表示不限，`null` 表示明确无 namespace。设置页读取元数据保留该区别，切换连接时使用目标连接默认库和独立只读上下文。

缓存按连接配置代次、控制台、运行表面、数据库、Schema 和会话上下文区分。列描述按需读取，独立队列串行、相同请求合并；TTL、对象上限、LRU 和失效代次限制资源。字段的隐藏、生成和自增属性会保留，用于准确展开及写入提示。

临时对象是控制台本地的已确认事实，不通过另一条连接描述。支持跟踪创建、删除、事务、保存点与方言相应的回滚规则；CTAS 或失败批次无法确认的形状保持未知。

## 能力边界

| 范围 | 当前实现与限制 |
| --- | --- |
| MySQL / PostgreSQL / SQLite | 有查询块与投影重写语义用例。属于受测语法子集，不等同于完整数据库语法验证器 |
| 其他已登记 SQL 方言 | 明确提供词法、对象、函数、引号或分页能力；结构重写按能力关闭 |
| 未知驱动 | 通用安全关键词，不默认套用 MySQL 函数或重写 |
| 存储过程及复杂递归 / 厂商语法 | 不承诺完整过程体、类型与版本语义推断 |
| USE、SET ROLE、search_path 等会话变化 | 保守暂停结构补全，提示重新连接；不假定旧上下文仍有效 |
| 大文档 | 运行时超过 200,000 字符暂停自动分析，保留编辑和执行能力 |
| 轻量编辑器 | 同引擎、同行摘要与直接接受；接受时选中首个占位符，完整 linked-placeholder 跳转由 Monaco 提供 |
| 用户函数 / 枚举 / 局部覆盖 | 可视化表单和经过校验的声明式 JSON；没有执行自定义 JavaScript |
| 版本覆盖、独立候选类别开关 | 尚未提供专门的设置界面；不宣称已实现所有规划项 |
| 自选字段查询向导 | 本轮提供持久字段组，不宣称已有独立的临时自选字段向导 |

未引入远程 AI、数据行采样或外部元数据上传。`dt-sql-parser` 与 `node-sql-parser` 的 POC 记录见 `test-results-db/database-sql-parser-poc.md`；没有把包大小与不完整语句适配成本直接带进工作台。
